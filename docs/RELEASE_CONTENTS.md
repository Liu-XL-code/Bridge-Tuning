# Source-only release contents

| Requested item | Included artifact |
|---|---|
| Method workflow | `assets/workflow.svg` |
| Code tree | `docs/CODE_TREE.md` |
| Datasets, sources and splits | `docs/DATASETS.md`, split generator and training documentation |
| Training parameters and code | CT/MRI YAML profiles, `train.py`, `run_cv.py`, shared engine |
| Inference and example | `infer.py`, native-grid output; example checkpoint generated by `run_smoke.py` |
| Experimental tables | Own-model historical results and dataset summaries with coverage flags |
| Visualizations | Synthetic montage, dataset tables and `visualize.py` |
| Example data | Twelve entirely synthetic NIfTI image/mask pairs and CSVs |
| Model implementation | Swin UNETR with FFT, decoder probing, BitFit and LoRA; no model weights |

No pretrained or trained weights are included, as requested. The synthetic smoke run
does not download weights and generates its own local models. Full pretrained training
requires a separately obtained compatible foundation initializer. No external DA
comparator code, private scans or raw patient-level experimental logs are included.
