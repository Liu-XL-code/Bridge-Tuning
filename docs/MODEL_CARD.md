# Model architecture and externally supplied checkpoints

No pretrained weights, trained weights, optimizer states or checkpoint binaries are
included in this source-only release. The model and all adaptation code are included.

## Model

The segmentation network is MONAI Swin UNETR with one input channel, two output classes,
feature_size=48 and 96-cubed windows. The software check uses feature_size=12 and
64-cubed windows. CT and MRI preprocessing, adaptation strategy and label rules are
explicit in the YAML profiles. Training embeds the resolved config in each checkpoint.

## Foundation initialization

The study attributes supervised multi-organ initialization to
[FSEFT](https://github.com/jusiro/fewshot-finetuning). Obtain a compatible checkpoint
separately from the original provider and respect its conditions. No claim is made
that an arbitrary current upstream checkpoint is byte-identical to the archived model.

Convert a trusted legacy state dictionary using `convert_checkpoint.py --trusted
--backbone-only --role foundation`, with the chosen config, input and output paths.
The converter strips wrapper prefixes and the upstream classifier/head. It removes
optimizer/config path metadata but does not repair incompatible tensor keys or shapes.
Initialization requires every non-head tensor to match. A backbone-only checkpoint
is rejected for direct binary inference.

## Models generated by this code

- `run_smoke.py` creates `runs/smoke/bridge/selected.pt` and
  `runs/smoke/target/selected.pt` from synthetic data without downloading weights.
- Full A -> B training produces a bridge checkpoint in its specified output directory.
- B -> C K-shot LoRA adaptation produces a target checkpoint for `infer.py` and
  `evaluate.py`. FFT, decoder-only probing and BitFit use the same interface.

Release checkpoints store tensors plus built-in metadata, and are loaded using
`weights_only=True`. Their embedded config recreates the LoRA architecture before
strict loading. Initialization can merge a previously trained LoRA state before
inserting fresh adapters for a new stage. These files are generated by the user;
none are supplied in the ZIP.

The included historical verification receipts and synthetic montage document tests
previously run with separately available checkpoints. They do not imply that those
weights, an original main-table target model, or clinical predictions are included.
